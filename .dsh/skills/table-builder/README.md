## 1. 职责
从库里读一批热点条目，按四类汇总成表格：每类条数、热度合计、热度均值、代表标题，并给出合计行。产出 Markdown 与人机两用的 CSV，回填批次的 `table_path`。

## 2. 输入

| 字段 | 类型 | 必填 | 说明 | 来源 |
| --- | --- | --- | --- | --- |
| `--batch` | 文本 | 二选一 | 批次号 | 命令行/库中批次表 |
| `--latest` | 开关 | 二选一 | 等价于不传 `--batch`（用最近一批） | 命令行 |
| `--kw` | 文本 | 否 | 按标题关键词过滤 | 命令行 |
| `--category` | 枚举 | 否 | 只看某一类（四类之一） | 命令行 |
| `--fmt` | 枚举 | 否 | 输出格式 both / md / csv（默认 both） | 命令行 |
| `--out-dir` | 目录 | 否 | 输出目录；缺省 `workspace/hotspots/<批次号>` | 命令行 |

## 3. 输入校验（进场前，不通过直接退回）
1. 库里必须有这个批次；没给 `--batch` 也没给 `--latest` 时取最近一批，最近一批不存在就退回。
2. 批次下必须有条目（空批次不出表，直接退回）。
3. `--category` 必须是四类之一（argparse 已限枚举）。

## 4. 输出
- `workspace/hotspots/<批次号>/hotspot-table-<时间戳>.md`（分类汇总表）。
- `…/hotspot-table-<时间戳>.csv`（同内容 CSV）。
- 回填 `hotspot_batches.table_path`。

## 5. 完成判据（自检通过才交给下游）
- 表格含表头 `| 分类 | 条数 | 热度合计 | 热度均值 | 代表标题 |` 与合计行。
- 四类条数之和 = 表内总条数；过滤条件在输出里写明。
- Markdown 与 CSV 行数一致。

## 6. 失败处理

| 失败情形 | 处理 | 上限 | 超限后 |
| --- | --- | --- | --- |
| 批次不存在或条目为空 | 退出 2，提示先跑 hotspot-collector | — | — |
| 写文件失败（目录不可写） | 退出 1 并回报磁盘问题 | 1 次 | 转人工检查目录权限 |

## 7. 依赖
`_shared/hotspots.py`（aggregate / render_table / render_summary）、`_shared/recording.py`、`_shared/db.py`。
